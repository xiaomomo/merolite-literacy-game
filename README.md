# 🌸 美乐蒂识字大冒险

专为 6 岁儿童设计的识字游戏，通过游戏化方式让孩子在冒险中自然识字。

## 🎮 游戏特色

### 三种游戏类型
1. **捉迷藏** 🙈 - 从 4 个选项中找出正确的字
2. **泡泡消除** 🫧 - 戳破含有正确字的泡泡
3. **拼图识字** 🧩 - 选择正确的字拼到拼板上

### 游戏化设计
- **5 个岛屿关卡**：花花岛 → 泡泡海 → 星星山 → 拼图森林 → 月光城堡
- **爱心货币**：找到字宝宝获得爱心，可以买装饰
- **每日惊喜**：每天登录获得随机爱心和贴纸
- **城堡装饰**：用爱心购买 12 种装饰品装扮城堡

### 视觉效果
- Canvas 路径动画（粉色虚线流动）
- 云朵飘动、小鸟飞翔装饰
- 泡泡浮动和爆破效果
- 彩带庆祝动画
- 字宝宝出现动画

## 📊 游戏数据

- **字库**：100 个汉字
  - 家庭篇（爸爸妈妈爷爷奶奶...）
  - 身体篇（头耳目口鼻手足...）
  - 数字篇（一二三四五六七八...）
  - 自然篇·天地（日月星辰风云...）
  - 自然篇·山水（山水火土金石...）

- **岛屿**：5 个（每个岛屿 5 个字宝宝）
- **游戏类型**：3 种
- **装饰物品**：12 种
- **贴纸**：10 种

## 🎯 游戏流程

```
打开游戏
   ↓
每日登录 → 打开礼物（+5~10 爱心 + 随机贴纸）
   ↓
地图界面 → 选择岛屿（解锁下一个岛屿需完成前一个 3 个字）
   ↓
美乐蒂讲故事
   ↓
选择游戏类型（捉迷藏/泡泡/拼图）
   ↓
玩游戏找字宝宝（每轮 3 个字）
   ↓
找到字宝宝 → 庆祝动画 → 送回家（+3 爱心）
   ↓
继续下一个字 或 返回地图
   ↓
查看城堡/背包/商店
```

## 💡 设计理念

1. **游戏 > 学习**：没有"学习任务"的感觉，只有"冒险找字宝宝"
2. **正向反馈**：每次答对都有音效 + 动画 + 奖励
3. **自主选择**：孩子可以选择喜欢的游戏类型
4. **收集乐趣**：字宝宝住进城堡、收集贴纸、购买装饰
5. **适度原则**：每轮 3 个字，保持意犹未尽的感觉

## 🎨 视觉风格

- **主色调**：粉色系（#FFE4E1, #FFB6C1, #FF69B4）
- **字体**：ZCOOL KuaiLe（卡通字体）
- **动画**：柔和、可爱、有弹性
- **按钮**：大、圆、容易点击（适配 iPad 触摸）

## 🔧 技术栈

- 纯 HTML/CSS/JavaScript
- Canvas 动画（路径、泡泡）
- Web Audio API（音效）
- Speech Synthesis（语音朗读）
- localStorage（存档）

## 📝 存档内容

游戏自动保存在浏览器 localStorage：
- 冒险天数
- 爱心数量
- 找到的字宝宝
- 拥有的贴纸和装饰
- 岛屿进度
